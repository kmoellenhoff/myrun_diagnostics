### Auswertung
- **Encoder liefert nach der Reinigung saubere Werte** (gleichmäßig, keine Aussetzer während der Bewegung) [M].
- **Die GIRT sieht das Encodersignal selbst**: Bandbewegung ohne Fahrbefehl → Code 08 innerhalb von ≈ 4 s [M/O]. Code 08 ist damit (mindestens auch) eine **Plausibilitätsprüfung „Drehzahl passt nicht zum Antriebszustand“**, nicht nur „Sensor defekt“ [I]. Umgekehrt (Antrieb an, keine/zu wenige Impulse) wäre derselbe Code zu erwarten → passt zu den 8er-Abbrüchen beim Start mit verschmutztem Sensor [H].
- **HF901 = GIRT-Fehler im Wartezustand** (`QSWaitForStart901`), im Unterschied zu 902 (Lauf) und 904 (Start) [I].
- Reihenfolge belegt: **erst GIRT-Fehler, dann nimmt die Konsole EM_POWENA zurück** (≈ 1,8 s später). Ein EM_POWENA-Abfall ist also typischerweise Folge, nicht Ursache [M].
- Bandbewegung im Standby löst den Fehler aus → für künftige Tests Band vor START nicht bewegen.

### Auswertung (12:45 und 12:58 zusammen)
- Zwei Fehlstarts direkt nach Kaltstart, Sensor sauber und nachweislich funktionsfähig (Handtest: Konsole **und** GIRT sehen die Impulse) [M].
- **STS2 8× = Code 08** bedeutet damit hier: „Antrieb angefordert, aber keine Drehzahlimpulse“ – also **Folge davon, dass der Motor nicht dreht**, nicht Sensordefekt [I].
- Offene Frage bleibt dieselbe: Versucht die GIRT überhaupt, Q2 zu schalten? → Messung Testpad Basis T2 und Zwischenkreis bzw. DC MOTOR beim nächsten Fehlstart.
- `@STATUS# Info:` war bei beiden Fehlstarts 000008 (passt zu Code 08); im Handtest-Fehler aber 000055 – Bedeutung unklar [O].
- **Zwischenkreis beim Fehlstart 12:58: konstant 316 V** (Netzscheitelwert) [M]. Die PFC (L4981AD) hat beim Start nicht hochgesetzt. Ob sie in einem guten Lauf hochsetzt, ist nicht gemessen; typisch wären ≈ 380–395 V [I].
- **Hypothese [H]:** Die gemeinsame Versorgung VCC von L4981 (Pin 19) **und** Gate-Treiber (VDD, Pad C) fehlt beim Start bzw. wird von der GIRT nicht zugeschaltet. Dann laufen weder PFC noch Q2 → Motor 0 V → keine Encoderimpulse → Code 08 → 904. Erklärt alle Beobachtungen eines Fehlstarts mit einer Ursache; der Wackelkontakt am Treiber-VDD (11.11. nachgelötet) liegt im selben Netz.
- Nächste Messung: VDD (Pad C / L4981 Pin 19 / Kondensatorpin mit 0 Ω zu VDD) gegen 0VA, DC 20 V, MIN/MAX – im Standby und beim Start; parallel Testpad Basis T2 (MAX).
- **Kein Relaisklicken** beim START-Versuch, danach oder beim Abbruch (Nutzer, 12:58) [O]. Beim Netz-Ein nicht gezielt darauf geachtet.
- Folgerung [I]: Schließt F27 (Vorladerelais, statisch in Ordnung) im Betrieb nie, läuft alles über 68 Ω. Im Standby fällt das nicht auf (kein Strom, 316 V); eine GIRT, die den Zustand des Vorladekreises überwacht, würde PFC und Antrieb dann nicht freigeben. Prüfen: Spule F27 – Spulen-Minus gegen 0VA (≈ 24 V = nicht angesteuert, ≈ 0 V = angesteuert; zeigt zugleich, ob +24 V da ist).
