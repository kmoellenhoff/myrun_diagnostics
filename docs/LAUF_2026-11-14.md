### Auswertung
- **Encoder liefert nach der Reinigung saubere Werte** (gleichmäßig, keine Aussetzer während der Bewegung) [M].
- **Die GIRT sieht das Encodersignal selbst**: Bandbewegung ohne Fahrbefehl → Code 08 innerhalb von ≈ 4 s [M/O]. Code 08 ist damit (mindestens auch) eine **Plausibilitätsprüfung „Drehzahl passt nicht zum Antriebszustand“**, nicht nur „Sensor defekt“ [I]. Umgekehrt (Antrieb an, keine/zu wenige Impulse) wäre derselbe Code zu erwarten → passt zu den 8er-Abbrüchen beim Start mit verschmutztem Sensor [H].
- **HF901 = GIRT-Fehler im Wartezustand** (`QSWaitForStart901`), im Unterschied zu 902 (Lauf) und 904 (Start) [I].
- Reihenfolge belegt: **erst GIRT-Fehler, dann nimmt die Konsole EM_POWENA zurück** (≈ 1,8 s später). Ein EM_POWENA-Abfall ist also typischerweise Folge, nicht Ursache [M].
- Bandbewegung im Standby löst den Fehler aus → für künftige Tests Band vor START nicht bewegen.
